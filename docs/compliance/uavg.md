# UAVG (Netherlands)

* Child consent age is configured as 16 for information-society services (UAVG implementation of GDPR Art. 8) - **verify the article reference with counsel before relying on it**.
* BSN (national identification number) processing is restricted by Dutch law; SLAI classifies it as a national identifier requiring a registered legal basis. It is never stored in memory/ledger (the ledger holds pseudonymous IDs only).
* Notification to the Autoriteit Persoonsgegevens is an organisational act performed by an authorised person; the software only prepares drafts and tracks the 72h deadline.
* DPO appointment, DPIA and prior consultation are organisational (see `deployment_compliance.md`).
