# SLAI v2.4 — LSTP v0.1 benchmark (PowerShell)

This is a **reviewable, read-only proposal** for `SLAI/benchmarks/lstp/`.
It does not update the SLAI submodule, modify existing agents, publish changes,
train LANTRA, or execute instructions generated by an AI model. The benchmark
measures semantic-field extraction from up to 5,400 distinct synthetic cases.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7+, Git, Python 3.12 (`py -3.12`), Node.js.
- A local SLAI v2.4 checkout, the extracted `benchmarks/lstp/` folder, and an
  LSTP checkout. Network access is required for dependency installation and
  live calls. The verification commands themselves require no provider keys.
- OpenAI and Gemini API access with at most **$5 each** available to this pilot.
- A Groq account **confirmed by you** to be on a free tier. The script cannot
  query Groq billing plan information and must not be used with a paid Groq tier.
- Before using `-ConfirmPricing`, check current standard text prices against
  the sources in `providers.py` (reference date: 2026-11-17).

## 1. Clone SLAI (only if you do not already have it)

From **PowerShell**:

```powershell
Set-Location 'G:\GAIA\AI'
git clone --branch SLAI-v.2.4 --single-branch https://github.com/The-Outsider-97/SLAI.git SLAI
Set-Location 'G:\GAIA\AI\SLAI'
```

If that folder already exists, use `Set-Location` only: do not clone over it.
Copy the provided `benchmarks/lstp/` package into that checkout without
replacing an existing file. The downloadable ZIP has paths relative to the
SLAI repository root.

## 2. Get LSTP and choose the version you want to benchmark

**Current LSTP main**, recommended for this experiment:

```powershell
Set-Location 'G:\GAIA\AI'
git clone https://github.com/The-Outsider-97/LSTP.git LSTP
git -C 'G:\GAIA\AI\LSTP' rev-parse HEAD
```

If `G:\GAIA\AI\LSTP` already exists, inspect its status/commit first and
update it yourself only after reviewing local changes. Do not use `git reset`
or overwrite your checkout. The scripts never pull or switch revisions.

**SLAI's pinned LSTP submodule**, an alternative for integration comparisons:

```powershell
Set-Location 'G:\GAIA\AI\SLAI'
git submodule update --init -- model/LSTP
git -C .\model\LSTP rev-parse HEAD
```

The inspected SLAI v2.4 submodule gitlink and `model/lstp.lock.json` revision
do not match. This package does **not** resolve that repository inconsistency.
The report records the exact code SHA you chose.

## 3. Install, verify and run an offline test

```powershell
Set-Location 'G:\GAIA\AI\SLAI'
.\benchmarks\lstp\run_benchmark.ps1 -LSTPPath 'G:\GAIA\AI\LSTP'
```

This creates an isolated `.venv-lstp-benchmark`, installs LSTP's development
dependencies, runs its schema check, core Python conformance tests, the independent
JavaScript verifier, the SLAI adapter smoke test, and the complete engineering
release check, then generates
the default 1,000 paired cases and an **offline (pending)** report.

The full release check may currently fail due to existing Ruff findings and
will stop before reaching the broader Python suite. Run `python -m pytest`
separately in the LSTP checkout if you need additional comprehensive evidence.
That result is recorded separately. **Live calls remain forbidden** if the
schema, Python conformance tests, JavaScript interoperability, or SLAI adapter
smoke test fails.

Check that the LSTP CLI is installed:

```powershell
& '.\.venv-lstp-benchmark\Scripts\python.exe' -m lstp --version
& '.\.venv-lstp-benchmark\Scripts\python.exe' -m lstp --help
```

LSTP is a protocol library, not a standalone conversational model or web UI.

## 4. Run the budget-limited benchmark with all three providers

**Do not paste API keys into transcripts or this chat.** The script reads only
the three provider keys from the already-existing SLAI root `.env` without
printing their values. Existing environment variables take precedence; if a
key is missing it is requested as a hidden input for this session only.

```powershell
Set-Location 'G:\GAIA\AI\SLAI'
.\benchmarks\lstp\run_benchmark.ps1 -LSTPPath 'G:\GAIA\AI\LSTP' `
    -RunName 'paired_1000_v02' -Cases 1000 -Live -ConfirmPricing -ConfirmGroqFreeTier -SkipInstall
```

Read the confirmations literally:

- `-ConfirmPricing`: you have checked current rates for the automatically
  selected model families against official sources.
- `-ConfirmGroqFreeTier`: your Groq account will not generate paid API usage.

The former pilot required provider list-models endpoints, which can reject
read access with HTTP 403 even when inference may be authorized. Model selection
now uses a **documented, known-priced model preference**, without making
an optional list-models request: OpenAI `gpt-6-luna`, Groq
`openai/gpt-oss-20b`, Gemini `gemini-2.5-flash-lite`. Each provider enforces
permissions on actual generation. If an inference endpoint returns 403, the
affected provider stops; no permission restrictions are bypassed. Optional
environment overrides `LSTP_OPENAI_MODEL`, `LSTP_GROQ_MODEL` and
`LSTP_GEMINI_MODEL` can select other *already whitelisted* models.

Planned requests: **1,000 cases × 3 formats × 3 models = 9,000 API calls**.
Jobs are randomized as three-format blocks so complete paired comparisons are
prioritized. The spending guard stops a paid provider before starting a block
it estimates cannot fit the remaining budget. The entire run may not finish
within $5 per paid provider; incomplete conditions are reported as partial.
The Groq free tier may hit request/day or token/day limits and stop early.
Rate limits, budget limits, provider failures and interruptions leave a partial
report; running the **same command** resumes completed jobs safely.

## 5. Read the final report

```powershell
Set-Location 'G:\GAIA\AI\SLAI'
Get-Content '.\benchmarks\lstp\results\paired_1000_v02\final_report.md'
Invoke-Item '.\benchmarks\lstp\results\paired_1000_v02\final_report.md'
```

Generated files are under `benchmarks/lstp/results/paired_1000_v02/`:

| File | Meaning |
| --- | --- |
| `preflight.json` + `*.log` | Offline release, Python, schema, JavaScript and SLAI adapter evidence |
| `cases.jsonl` | Immutable paired inputs and gold-field annotations |
| `manifest.json` | Exact LSTP/SLAI commit, benchmark-code digest, dataset hash, model IDs and pricing sources |
| `results.jsonl` | One raw response, usage and score per attempted request |
| `budget_ledger.json` | Persistent conservative provider-specific spending guard |
| `final_report.json` | Structured results, per-model metrics and paired differences |
| `final_report.md` | Human-readable summary with limitations and status |

`MEASURED` means all planned requests succeeded. `BUDGET_LIMITED` means a
conservative guard stopped additional work without exceeding its local cap;
only observed paired samples can be interpreted. `PARTIAL_OR_PENDING` means
missing requests, provider errors or no live data. A report never asserts an
unmeasured benefit.

## What this benchmark can and cannot establish

It compares natural-language, ordinary-JSON and canonical-LSTP representations
of the **same semantic facts** within each selected model. The primary metric
is exact recovery of seven target fields; secondary metrics are JSON validity,
field accuracy, latency, token counts and nominal API cost. A 95% Wilson
interval summarizes each observed exact-match proportion.

It **does not** benchmark all human communication, hallucination rates, real
tool execution, native model training or every possible AI-to-AI handoff.
Future phases should add independent human-annotated tasks, held-out real
multi-agent workflows, and a separately controlled structured-output mode.

The local budget guard reserves up to three times the expected maximum
request price before every paid request and stores crash-safe reservations.
It is a deliberately conservative estimate, **not a billing-provider hard cap**:
provider-side price changes, taxes or usage outside this runner cannot be
controlled here. Confirm account-level spending limits separately whenever
the provider offers them.
